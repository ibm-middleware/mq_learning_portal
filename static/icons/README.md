# Icons used by this portal

Only the marks required by the two Native HA architecture pages are shipped.
The running portal does not fetch icons from the network.

| `kubernetes/resources/pod.svg` | Internals diagram | Apache-2.0 / CC BY 4.0 |
| `tabler/outline/` | Internals process icons | MIT (`tabler/LICENSE`) |

Generic UI icons (users, globe, chart, menu, search) come from
`static/js/lucide.min.js` (ISC).

Vendor **marks** must be used as provided for product identification only.
Do not recolor, add effects, or combine them into a new logo. Trademark
rules still apply; see the root `NOTICE` file.
